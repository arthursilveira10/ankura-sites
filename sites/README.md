# sites

Uma pasta por cliente/página, no formato `[cliente-pagina]/` (ver estrutura no `CLAUDE.md`).

- `briefing.md`, `arquitetura.md`, `copy.md`, `revisao.md` e `assets/` ficam no repositório da Ankura.
- `site/` é o código do cliente e tem **repositório próprio no GitHub** (ignorado pelo git deste workspace). Assim cada médico só enxerga o próprio site no editor.
