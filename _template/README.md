# _template

Site-base reutilizável da Ankura. Em construção na Fase 4 (ver `PASSAGEM-FASE-4.md`).

- Stack: Astro + Tailwind v4, com tema (cores, fontes, raios) por cliente num arquivo só.
- Conteúdo em arquivos de dados com regras de formato, pronto para o editor (CMS).
- Demo: Dr. Arthur Silveira [FICTÍCIO], dermatologia, home + 2 procedimentos + modo LP.
- Contato: somente botão de WhatsApp, com mensagem pronta por página.
- Deploy padrão: Cloudflare. Funciona em qualquer hospedagem de site estático.

Para começar um cliente: copiar esta pasta para `sites/[cliente-pagina]/site/` e criar o repositório próprio do cliente (passo a passo na skill `site-build`).
